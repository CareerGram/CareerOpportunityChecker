How the system works

Start with a job description in the Streamlit interface. The backend calls the relevant model or helper module, then returns the result for display. Click a component above to explore it.

File: Choose a component to view its file or role.

Important: A model prediction, LIME explanation, or warning flag is not proof that a job is fake. Resume matching is a skill comparison, not a hiring guarantee. Users should verify opportunities independently.
